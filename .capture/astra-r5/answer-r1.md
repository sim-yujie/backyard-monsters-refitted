(astra round 1, 22 Nov. The run hit the Codex usage limit after its edits and its tsc check, before it wrote the FIXED / NOT FIXED lists; this is its review text taken from log-r1.txt. Its edits are in the commit that adds this file.)

**HIGH**

- **Pictures 13–15, 17: “Done” spills past its painted button.** The modern button is too narrow for its label. Give it sufficient width and keep the text inside the painted face, using the same reserved space in both themes.
- **Pictures 5–6: the short desktop window exposes only the tops of the monster cards and detail panel.** Essential selection and quantity controls sit below the frame without a visible scrolling cue. Make the lower content explicitly scrollable within the window and retain a visible scrollbar; keep the title, tabs and queue in place.

**MEDIUM**

- **Pictures 1–7, 19: rail actions change meaning visually as space shrinks.** The full chips distinguish “Send” from their body, but the narrow `3 ▸` buttons look like navigation, although they send immediately. Use a short explicit `3 Send` label in the narrow form. The rail is a useful use of the desktop space at two, four and six presets. Repeating Send on the Presets side is acceptable: it keeps the shortcut stable.
- **Pictures 10–12: sideways scrolling is too easy to miss.** The fading monster could read as disabled—especially beside the genuinely locked monster in preset 5—and the fade obscures quantities. Add a small directional cue at the strip edge when more stacks exist, and reduce the fade so the count remains readable. Keep the number, cost and Send fixed.
- **Pictures 13–15, 20: the count’s scope is inconsistent.** Modern marks the last logical stack’s boxes, but Classic’s crowded adjoining boxes weaken that grouping; the pencil singles out only the final box. Keep a clear gap between boxes in both themes and apply the same distinct outline to every box belonging to the last stack. In picture 15, `30` must visibly correspond to `20 + 10`.

**LOW**

- **Pictures 8–9: the desktop order list is very small.** Slightly larger text would improve readability, though the box grid already provides the primary sequence.
- **Pictures 13–15, 17, 20: the grid and “N left” communicate capacity well.** The dashed next box is a useful preview, but its low-opacity monster is faint. A little more contrast would help without giving it the appearance of an occupied box.
