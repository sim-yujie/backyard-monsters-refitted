# v2.0.0-beta.6.4

Raids:
- The Trojan Horse now sends its whole army. Before, the fight could end after a few seconds and the last monsters never came out.
- Raid monsters start loading when the raid warning appears. On a slow connection you now see a softer picture of each monster while the full one loads, instead of green squares.

Graphics:
- Towers and buildings with very large pictures no longer show as black boxes on older phones and computers.
- Players whose browser has graphics turned off now see a message explaining how to turn them on, instead of a broken screen.

Fixes:
- Firefox on some Windows PCs no longer fills the error log on every mouse move.
- Leaving your yard for the map before the ground has finished drawing no longer causes an error.
