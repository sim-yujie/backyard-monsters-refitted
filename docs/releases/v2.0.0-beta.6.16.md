# v2.0.0-beta.6.16

Fixes:
- Inferno attacks where you send a champion together with a full Flinger now count properly. The champion takes up part of the Flinger's room (as in the original game), and the attack screen now leaves that room free. Before this fix, the screen sent the champion on top of a full load, the server fought the attack with fewer monsters, and the result could be refused.
- If the server does refuse an attack on a Descent or tribe yard, the message now says the server will still settle it from its own replay in a few minutes. It used to say nothing was saved, which was wrong.
- Trap re-arm works again for players who built new traps by hand on spots where traps had gone off. Those old spots stayed on the re-arm list, so the list could show more traps than you own (for example 41 instead of 24) and re-arm refused every time. The list is now cleaned automatically; reload the game once to get the corrected list.
- In the Descent, if your screen and the server disagree about an attack, the server now keeps its own full replay of the fight (damage, loot, whether the level is beaten) instead of refusing it and falling back to a shorter fight. The result screen tells you when this happens.
