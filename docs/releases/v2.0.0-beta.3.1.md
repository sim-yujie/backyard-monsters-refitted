# v2.0.0-beta.3.1

Fixed a privacy problem: when you visited, helped or attacked another player's yard, the game
quietly sent along that player's saved Yard Planner layouts (trap spots included). Now only you
get your own layouts.

Also closed a cheat: a hand-made Inferno attack save could add a champion or
raise a champion's level. An attack now only ever lowers your champion's health, as everywhere else.
