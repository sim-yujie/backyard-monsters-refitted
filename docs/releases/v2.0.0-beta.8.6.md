# v2.0.0-beta.8.6

## World map
- Dragging and zooming the map is smoother when you or your alliance hold many
  outposts.
- The map no longer reloads when an alliance mate takes an outpost.
- Fogged areas load faster.
- Rivers are drawn in the background, so the map no longer pauses to draw them.

## Attacks
- Two players can no longer start an attack on the same yard at the same moment.
- Krallen has no Mode any more: she always fights as in Flash, hitting buildings
  she has not looted yet first.
