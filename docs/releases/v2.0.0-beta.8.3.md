# v2.0.0-beta.8.3

## Walls
- Fixed monsters **hitting a building through a wall** when the building stood right
  beside it. Monsters now have to break the wall first.
- In battle, every building now stands exactly where it is drawn. Some were up to one
  tile off, so some towers now reach slightly differently.
- Replays of defences from before this patch can no longer be watched.

## Repeat attack
- The camp panel now warns when an attack won't save a Repeat plan, and why. Attack over
  says it too.

## Alliances
- Fixed **"Goal set" and "Goal done" lines** not showing in the alliance feed and chat.

## Game team
- The admin dashboard now counts which monsters are flung in attacks, for balancing.
  Players see no change.
