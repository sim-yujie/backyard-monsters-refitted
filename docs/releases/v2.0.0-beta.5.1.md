# v2.0.0-beta.5.1

Fixes for phones and tablets:
- Opening the Champion Cage with a tap no longer presses the button that appears under your finger.
  Champions were sometimes frozen into the Champion Chamber by the same tap that opened the cage.
  The Map Room and the Inferno cave had the same problem and are fixed too.
- "Feed with Shiny" (and every other pay-with-Shiny button) keeps its size after the first tap, so the
  second tap feeds instead of landing on "Evolve now".
