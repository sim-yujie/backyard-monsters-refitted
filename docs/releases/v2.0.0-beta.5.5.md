# v2.0.0-beta.5.5

Country chat:
- You can now tell us which country you play from: in Account settings, or in the short question
  that appears once after you log in ("Not now" is fine, and you can set it later).
- Players from the Philippines get their own Philippines chat room, as a second tab next to Global,
  to chat in Tagalog or any language they like.
- Global chat stays open to everyone and is in English.
- More countries can get their own room later.
- Each country shows with its flag.

Layout (players reported it):
- Picking up or moving a building in Layout no longer opens a building window over the yard, on any
  screen, so nothing covers the yard while you line things up.
- Upgrade planning in Layout is gone: upgrade each building with its own Upgrade button. Upgrade
  walls stays in Layout.
- On phones, Select all, Mirror, Align and Distribute are now under More > Selection.
