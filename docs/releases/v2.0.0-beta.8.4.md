# v2.0.0-beta.8.4

## Attacks
- If your game page is older than the server, starting an attack now asks you to
  **reload** first. No monsters are spent. Before, the attack ran and the server
  replaced its result with its own.
- Attacks from an older page are no longer counted as suspicious.

## Loot
- Attack over no longer says **"Your storage was full"** when storage had room. Loot
  lowered by an alliance weakness now shows just the amount gained.
