# v2.0.0-beta.7.11

Fixes:
- iPhone and iPad: the game no longer runs out of memory and closes on the yard. Phones and tablets now start on Medium quality, and High on a phone or tablet uses lighter monster pictures. Monster pictures now load two at a time instead of all at once.
- If the game fails to load twice in a row, it switches to Low quality and says so. You can change it back in Settings.
- A quality you already picked in Settings is kept.
