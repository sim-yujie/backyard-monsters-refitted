# v2.0.0-beta.7.5

Changes:
- Piñata horse: tapping the horse now counts as being active, so it can start right after you log in.
- Hatch window: the button says just "Add". The line above it says where the monsters go.

Fixes:
- Wild raids: you can no longer get stuck on "The raid is over..." when the server is slow to answer. After a few seconds a short "Raid over · Back to yard" notice takes you home.
- Wild raids: going back to your yard before the result arrives no longer loses the raid. The damage, loot and result still land, and the result shows once in the yard you are in.
- Piñata horse: if it refuses to start, it now says why.
- Yard defended: the pop-up after a Piñata horse fight shows the whole horse.
- iPhone: the game no longer crashes when signing in again while the Shiny Lock is on.
- Move Monsters: pressing Fill no longer brings up a scroll bar that moves the button away.
